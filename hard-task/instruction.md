# Hard Task

Your job is to compute the sum of the first 50 prime numbers. You can use any programming language or tools you like, but you must provide a clear explanation of your approach and the code you used to arrive at the answer.

Return your results at `/app/result.json` in the following format:

```json
{
  "count": 50,
  "sum": <the sum of the first 50 prime numbers>,
  "max": <the largest prime number among the first 50 primes>,
  "primes": [<list of the first 50 prime numbers>]
}
```

Make no mistakes
